# Security Policy

## Supported Versions

Currently, only the latest version of Reputable on the `main` branch is supported with security updates.

## Reporting a Vulnerability

We take the security of Reputable very seriously. If you discover a vulnerability, please do **not** open a public issue. Instead, report it privately:

1. Email the maintainer at `alinairfan962@gmail.com`.
2. Please include a description of the vulnerability, steps to reproduce it, and any potential impact you've identified.

We will respond within 48 hours to acknowledge the report and provide an estimated timeline for resolution. Once the issue is resolved, we will publish a security advisory and notify you. Thank you for helping keep the community safe!
